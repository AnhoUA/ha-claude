# Changelog

## 0.4.4

- Посилання для входу в Claude можна просто клікнути в терміналі, по будь-якому його рядку. Відкривається повний URL, без переносів рядків, через які раніше виникала помилка «Невідома область: user:mcp_». tmux тепер передає гіперпосилання OSC 8 у веб-термінал.

## 0.4.3

- Текст у терміналі виділяється звичайним протягуванням мишею, без Option чи Shift: tmux більше не перехоплює мишу. Прокрутка коліщатком працює через історію веб-термінала.
- Посилання для входу в Claude виводиться одним рядком на вкладку **Log** доповнення, звідки його легко скопіювати. Там само видно, чи дійшло сповіщення в HA.
- Прибрано рядок стану tmux унизу термінала.

## 0.4.2

- Посилання для входу в Claude тепер приходить сповіщенням у Home Assistant (дзвіночок у бічній панелі). У терміналі довге посилання розбите на рядки, і скопіювати його було незручно. Після входу сповіщення зникає саме.
- Виділення мишею у веб-терміналі: на Mac з **Option**, на Windows і Linux із **Shift**.
- Копіювання з Claude (наприклад, «c to copy») передається в буфер обміну браузера через OSC 52.

## 0.4.1

- `anthropic_api_key` більше не показується на вкладці Configuration за замовчуванням: доповнення працює з підпискою claude.ai, а ключ можна задати через **Show unused optional configuration options**.

## 0.4.0

- Образ став мінімальним: Go, `build-base`, GitHub CLI і SSH-клієнт перенесено в окреме доповнення [ha-claude-go-dev](https://github.com/AnhoUA/ha-claude-go-dev).
- Прибрано опції `git_user_name`, `git_user_email` і `github_token`, тепер вони є в ha-claude-go-dev.
- Додано хуки запуску `/etc/claude/init.d/*.sh`, щоб похідні доповнення могли розширювати образ.
- Workflow збирання тепер reusable (`workflow_call`), тож похідні доповнення збираються й випускаються так само.
- `safe.directory` більше не дублюється в `~/.gitconfig` після кожного перезапуску.

## 0.3.0

- Перший публічний реліз.
- Claude Code у веб-терміналі в бічній панелі HA (ttyd + tmux).
- Claude стартує одразу в режимі Remote Control (`remote_control`, `session_name`).
- Go з `build-base`, git, GitHub CLI та SSH-клієнт; опції `git_user_name`, `git_user_email`, `github_token`.
- Постійне сховище `storage_path` (типово `/share/claude`) для скілів, агентів, команд, `CLAUDE.md` і проєктів.
- Готові образи для `amd64` і `aarch64` у GHCR: HA завантажує їх, а не збирає на пристрої.
